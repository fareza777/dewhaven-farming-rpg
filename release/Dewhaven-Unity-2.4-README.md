# Dewhaven 2.4 — Quiet World

Native Android portrait test candidate. Install `Dewhaven-Unity-2.4.apk` on an ARM64 Android 8+ device. It updates the same package as 2.3; keep the existing installation to retain its local farms. Previous APKs remain in this folder.

- Quieter nature ambience; the repeating bird bed is removed from playback.
- Four original, sparse ambient music loops. Music, nature, activity sounds and voice have separate controls. Set Music to zero for nature/SFX only.
- Nine compact landscapes with shorter curved trails, cottages, fishing bends, orchard clearings and distinct dungeon approaches. Four town street networks are rebuilt around the existing 44 buildings.
- Farm crops/equipment, relationships, quest IDs and offline English narration are retained. Old exterior positions outside the new boundaries land at a safe entrance.
- Small-screen audio controls accommodate larger text. Music quickly ducks under narration and pauses with the application or fullscreen advertising.

This is locally test-signed and uses Google's demo advertising IDs. It has editor verification; physical Android installation, touch/audio interruptions, real native insets, ads and thermal/frame-time performance still need device verification. It is not an owner-signed Play Store production upload.

The adjacent info JSON and SHA256 file describe the exact completed APK. Implementation and editor evidence are in `docs/unity/quiet-world-progress.md` and `docs/unity/android-quiet-world-package-check.json`.
